# DigiBand
This repository includes a Python-based stopwatch and digital clock with audio and high-quality graphics. You can customize this repository and use it without cheating, thanks to its encrypted JSON-based log.
# USAGE:
```bash
git clone https://github.com/coilfofficial/DigiBand.git
cd DigiBand
```

```python
python setup.py run.py main.py
###### *Or If you want Debug you can type:*
main.py --logdbg
```
